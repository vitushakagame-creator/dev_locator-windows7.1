ФАЙЛЫ И РЕЗЕРВНЫЕ КОПИИ

Центр данных

Этот раздел подключён к общей базе Supabase. Аккаунт и проекты доступны с любого устройства после входа в тот же аккаунт.

Аккаунт и резервные копии

Резервная копия переносит аккаунт и его проекты между браузерами. Кнопка «Сохранить всё в папку» создаёт Data/никнейм/account.json, метаданные и папки проектов — браузер попросит выбрать папку назначения.

Проверяю режим хранения…

Файлы проектов

Можно выгрузить прикреплённые файлы своих проектов по одному. Если файл есть в резервной копии, его содержимое будет восстановлено из неё.

Вспомогательные файлы DevSpace

Вспомогательные файлы из исходного проекта сохранены в архиве. Основные аккаунты, проекты и загруженные файлы теперь работают через Supabase.

Исходные вспомогательные файлы сохранены в ZIP-архиве; этот сайт больше не обращается к Python API.

Аккаунты, профили, проекты и лайки хранятся в Supabase PostgreSQL. Файлы проектов хранятся в Supabase Storage. Если настройки Supabase не заполнены, сайт покажет ошибку подключения и не будет имитировать регистрацию.

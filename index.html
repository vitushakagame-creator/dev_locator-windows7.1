ФАЙЛЫ И РЕЗЕРВНЫЕ КОПИИ

Центр данных

Этот раздел использует общий сервер DevSpace. Ниже доступны реальные вспомогательные файлы проекта: их можно скачать и запустить локально для создания папки данных или извлечения файлов из резервной копии аккаунта.

Аккаунт и резервные копии

Резервная копия переносит аккаунт и его проекты между браузерами. Кнопка «Сохранить всё в папку» создаёт Data/никнейм/account.json, метаданные и папки проектов — браузер попросит выбрать папку назначения.

Файлы проектов

Можно выгрузить прикреплённые файлы своих проектов по одному. Если файл есть в резервной копии, его содержимое будет восстановлено из неё.

Вспомогательные файлы DevSpace

Это не декоративные ссылки: файлы ниже лежат рядом с сервером и скачиваются с него. Python-скрипты запускаются на компьютере с Python; они не выполняются прямо внутри браузера и не заменяют общую серверную базу.

⬇ devspace_setup.py ⬇ devspace_import.py ⬇ devspace_data_helper.js ⬇ Инструкция
В опубликованном режиме аккаунты и проекты загружаются через Python API, а постоянные данные хранятся в PostgreSQL и DigitalOcean Spaces. Если сервер или постоянное хранилище не настроены, сайт должен показать ошибку подключения, а не притворяться, что данные синхронизированы.
